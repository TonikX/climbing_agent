# Climbing Journal Web

Адаптивный кабинет на React, TypeScript, Vite и Recharts. Экраны: обзор,
прогресс, история, попытки тренировки, профиль. Первая версия только для чтения.

## Запуск

Нужен Node.js 22.12+ (рекомендуется 24 LTS).

```sh
cd web
npm ci
npm run dev
```

Адрес выводится Vite. `/?demo=1` включает явно обозначенные демонстрационные
данные из `src/demo.ts`. В деморежиме запросов к API нет, фильтры отключены:
это фиксированный пример, а не расчёт статистики. Обычный `/` обращается к API.

```sh
npm run build
npm run preview
```

Сборка — `web/dist/`. Корневой пакет OpenClaw независим от frontend.
Dev proxy `/api` направлен на `http://127.0.0.1:8000` (см. `vite.config.ts`).
Для production сайт и API должны иметь один origin; секреты в `VITE_*` не нужны.

## API и ограничения первой версии

Клиент использует GET `/api/v1/auth/session`, `/statistics/month`,
`/statistics/progress`, `/trainings?include_test=false&limit=12` с курсором.
Агрегаты приходят с верхнего уровня DTO. Статистика не пересчитывается в JS.
Прогресс показывает до 6 месяцев с данными внутри периода, а не ежедневную активность.
Период и категория передаются в серверные фильтры и сохраняются в URL.
История пока показывает все даты: существующий список тренировок не поддерживает
эти фильтры. Это явно подписано в интерфейсе. Длительность null отображается как «—».
Тестовые попытки дополнительно скрываются в детализации.

Веб-авторизация реализована через Telegram OIDC и HttpOnly cookie.
Настройка и миграция — в `docs/web-authentication.md`. Клиент проверяет доступность
через `/auth/config`, переходит на `/auth/telegram/start`, получает профиль и CSRF
через `/auth/session`. Logout и logout-all используют CSRF; credential в JS не хранится.
Неизвестные и неподтверждённые пользователи направляются в бота для заявки.
Внутренний endpoint логина браузером не вызывается.

Для полного соответствия проекту backend также должен вернуть в истории
названия районов/секторов и серверную сводку каждой тренировки. Сейчас реальные
карточки используют дату, среду, длительность и попытки; названия мест из демо
не подставляются в настоящие данные. Веб-редактирование остаётся следующей очередью.

`web/Dockerfile` собирает статику в образ nginx. Compose использует её для `/`,
сохраняя прокси `/api`, webhook бота и запреты внутренних API. Секреты OIDC
передаются только API через серверный env-файл. Для локального HTTPS dev origin
и callback должны быть отдельно зарегистрированы в BotFather.
