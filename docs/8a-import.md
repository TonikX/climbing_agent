# Пробная проверка 8a.nu

Проверено 13 октября 2026 года. Данные в PostgreSQL не импортированы.

## Каталог

Публичная страница района:
https://www.8a.nu/areas/turkey/geyikbayiri/crags

На просмотренной версии указаны 59 crags и обычная пагинация; crag может
соответствовать сектору нашего каталога, но это требует проверки иерархии.
Пример списка маршрутов:
https://www.8a.nu/crags/sportclimbing/turkey/koridor/routes

На просмотренной версии указан 39 routes; первая страница содержит 20 записей,
названия, категории и ссылки. Доступные поиску версии могут быть устаревшими;
они не подтверждают актуальную полноту каталога. Информацию о чужих пользователях,
пролазах, рейтингах, текстах и фотографиях в каталог переносить не требуется.

## Результат сетевого опыта

Обычный GET к странице района, без авторизации, с User-Agent
`ClimbingJournalImporter/1.0 (AI-assisted; public climbing catalogue)`
получил страницу Cloudflare: `You have been blocked`.
Повторные запросы к каталогу, смена идентичности, прокси, воспроизведение
токенов или обход проверки не выполнялись.

robots.txt https://www.8a.nu/robots.txt отдельно запрещает GPTBot весь сайт,
а также ряд URL фильтров/поиска и списки `/sectors.../routes` для всех агентов.
Публичная видимость страницы не означает доступность автоматического GET.

Рабочий сетевой парсер не подтверждён. Для дальнейшей реализации нужен
сохранённый пользователем HTML или согласованная выгрузка/API. После получения
источника следует проверить реальные DOM/ID, пагинацию, привязку area/crag/sector,
сохранять источник `8a.nu` отдельно и явно сопоставлять его с существующим
публичным районом. Объединение трасс только по названию недопустимо.

В PostgreSQL эти данные пока не импортировались. Файлы не включаются в Git.

## Полный доступный каталог Гейкбаири

По отдельному запросу пользователя сохранён весь список района через тот же
авторизованный браузер. Индекс прочитан на трёх опубликованных страницах,
затем открыты ссылки всех 59 объектов. Навигация последовательная, с паузами
3–5 секунд; таблицы догружены обычной прокруткой до счётчика соответствующего
объекта. Прямые HTTP-запросы, закрытые API и перенос cookies не использовались.

Итог в `output/catalog/8a-geyikbayiri/`:

- 59 скальных объектов/crags, 65 сочетаний crag/внутреннего сектора;
- 1410 записей с уникальными URL: 1409 sportclimbing и 1 bouldering;
- сумма счётчиков сайта и сохранённых строк — 1410, совпадение для всех 59 объектов;
- нет пустых названий, категорий, секторов или URL;
- 62 снимка HTML таблиц: 3 страницы индекса и 59 списков маршрутов;
- `routes.csv`, `crags-index.csv`, `coverage.csv`, `review-needed.csv` и архив HTML.

161 запись относится к исходному `Unknown Crag`. Сохранены и обозначения N.N.,
неизвестных секторов и возможные варианты написания; их нельзя автоматически
отождествлять с известными маршрутами. Различаются скальный объект, внутренний
сектор и дисциплина. Это полнота **доступного списка сайта на момент сбора**,
а не утверждение о всех реально существующих трассах района.

Код для восстановления прогресса и сохранения через переданный cua_repl tab:
`scripts/eighta_browser_capture.mjs`. Это модуль для авторизованной браузерной
сессии, не самостоятельный HTTP-парсер и не фоновая джоба. Если среда запрещает
импорт локального модуля, те же документированные UI-операции выполняются
непосредственно в cua_repl. При остановке сохраняется CSV уже завершённых объектов;
перед продолжением следует проверить текущую страницу. Блокировки и проверки
авторизации не обходятся.

## Импорт в PostgreSQL 15 октября 2026 года

По запросу пользователя выполнено сопоставление с публичными секторами и трассами
существующего Гейкбаири, затем транзакционный импорт на сервер:

- 1133 новые трассы и 31 новый сектор;
- 225 ссылок на уже существующие трассы; их ID, названия и привязки сохранены;
- 116 ранее пустых категорий заполнены;
- 8 расхождений категорий сохранены в отчёте, известные категории не перезаписаны;
- 52 записи удержаны для проверки: 45 с повторяющимися именами внутри исходного
  сектора, 7 из Unknown Crag с совпадением имени уже существующей трассы;
- 1358 route refs, 65 section refs, 1 location ref источника `8a.nu`.

Неоднозначные записи сохранены **в PostgreSQL**, в `catalog_import_runs.report.pending`,
но не добавлены как возможные дубли в routes. Локально доступны `import/pending.csv`,
`import/grade-conflicts.csv` и `import/matched.csv` рядом с исходной выгрузкой.
Одна боулдеринговая запись отделена названием сектора с пометкой «боулдеринг»;
её источник и дисциплина сохраняются в URL, она не сопоставляется со спортивными трассами.

Сопоставление допускает нормализацию регистра/диакритики только внутри связанного
скального объекта/сектора. Разделение OSM left/right и агрегирующие группы 8a.nu
учтены без переноса существующих трасс в другой сектор. Свободный поиск совпадений
по всему району не используется, кроме обнаружения кандидатов для удержания Unknown Crag.
Внешние ключи источника — SHA-256 опубликованного URL, а не выдуманный числовой ID 8a.nu.

Код подготовки: `scripts/eighta_import.py`, входы — `routes.csv` и публичный
снимок существующего каталога. Скрипт только пишет SQL/отчёты. Исполнение — оператором
миграций, без расширения прав runtime/импортера AllClimb. SQL проверяет публичную
локацию, родителей, существующие ID/названия, внешние ссылки и итоговые счётчики.

status=`partial` из-за 52 записей, требующих проверки. Резервная копия и SQL:
`/srv/climbing-journal/backups/eighta-20261015T193141Z/`.
