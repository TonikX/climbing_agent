# Пробная проверка 8a.nu

Проверено 13 октября 2026 года. Данные в PostgreSQL не импортированы.

## Каталог

Публичная страница района:
https://www.8a.nu/areas/turkey/geyikbayiri/crags

На просмотренной версии указаны 59 crags и обычная пагинация; crag может
соответствовать сектору нашего каталога, но это требует проверки иерархии.
Пример списка маршрутов:
https://www.8a.nu/crags/sportclimbing/turkey/koridor/routes

На просмотренной версии указан 39 routes; первая страница содержит 20 записей,
названия, категории и ссылки. Доступные поиску версии могут быть устаревшими;
они не подтверждают актуальную полноту каталога. Информацию о чужих пользователях,
пролазах, рейтингах, текстах и фотографиях в каталог переносить не требуется.

## Результат сетевого опыта

Обычный GET к странице района, без авторизации, с User-Agent
`ClimbingJournalImporter/1.0 (AI-assisted; public climbing catalogue)`
получил страницу Cloudflare: `You have been blocked`.
Повторные запросы к каталогу, смена идентичности, прокси, воспроизведение
токенов или обход проверки не выполнялись.

robots.txt https://www.8a.nu/robots.txt отдельно запрещает GPTBot весь сайт,
а также ряд URL фильтров/поиска и списки `/sectors.../routes` для всех агентов.
Публичная видимость страницы не означает доступность автоматического GET.

Рабочий сетевой парсер не подтверждён. Для дальнейшей реализации нужен
сохранённый пользователем HTML или согласованная выгрузка/API. После получения
источника следует проверить реальные DOM/ID, пагинацию, привязку area/crag/sector,
сохранять источник `8a.nu` отдельно и явно сопоставлять его с существующим
публичным районом. Объединение трасс только по названию недопустимо.

## Проверка через браузер 15 октября 2026 года

Во встроенном браузере страница Küllüin открылась. До входа список трасс был
закрыт приглашением авторизоваться. Пользователь самостоятельно вошёл в аккаунт;
после его подтверждения в отображаемой таблице доступны 69 маршрутов.
Cookies, пароли и токены сессии не извлекались и не переносились в HTTP-клиент.

Сохранены `output/catalog/8a-kulluin/table.html` (снимок HTML именно таблицы,
а не всей страницы/сессии) и `routes.csv` (страна, район, crag, сектор, название,
категория, URL). В CSV 69 строк с 69 уникальными URL, пустых названий/категорий нет.
Все строки относятся к видимому сектору Küllüin. Это подтверждённое сохранение
одной доступной пользователю страницы, не работающий сетевой обходчик каталога.
В PostgreSQL эти данные пока не импортировались. Файлы не включаются в Git.
