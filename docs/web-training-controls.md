# Управление тренировками на сайте

После входа сайт отдельно проверяет активную тренировку без фильтров периода,
района и категории. Учитываются пустые тренировки и тренировки с одними
тестовыми записями; скрытие их из статистики не скрывает кнопки управления.

- Без активной тренировки доступна кнопка «Начать тренировку». В окне выбирают
  дату в часовом поясе пользователя и тип места: скалы или скалодром.
- Во время тренировки доступны «Текущая тренировка» и «Завершить тренировку».
  Первая открывает её сводку и пролазы. Вторая запрашивает подтверждение.
- Начало использует `POST /api/v1/trainings`; завершение —
  `POST /api/v1/trainings/{id}/finish`. Запросы защищены сессией, CSRF и ключом
  идемпотентности. Повторная отправка тех же данных использует прежний ключ.
- Необработанные сообщения бота автоматически не отменяются: при конфликте
  нужно дождаться сохранения записей и повторить завершение.
- Деморежим меняет состояние кнопок локально, не обращаясь к API сохранения.

Простой вид статистики используется по умолчанию. Ранее сохранённая настройка
localStorage больше не выбирает расширенный вид. Явный параметр
`?view=advanced` сохраняет смысл прямой ссылки; переключатель остаётся доступен.

## Ручная проверка

1. На тестовом аккаунте без тренировки нажать «Начать тренировку», проверить
   дату, выбрать тип места и подтвердить. Убедиться, что пустая тренировка
   открывается кнопкой «Текущая тренировка» и видна в боте.
2. Сменить период статистики так, чтобы дата тренировки была вне периода.
   Кнопки текущей тренировки и завершения должны остаться доступны.
3. Записать тестовый пролаз. Проверить его в текущей тренировке.
4. Нажать «Завершить тренировку» и отменить: тренировка остаётся активной.
5. Подтвердить завершение: появляется кнопка начала новой тренировки;
   завершение видно и в Telegram. Двойное нажатие не создаёт дубль запроса.
6. Открыть корневой адрес сайта без `view`: включён простой вид, даже если
   ранее в браузере выбирался расширенный. Проверить ручное переключение.
