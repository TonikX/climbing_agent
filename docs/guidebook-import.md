# Каталог из Antalya 2023 (PDF)

Предоставленный PDF — 114 страниц сканов без текстового слоя. Извлечение
работает локально, без LLM и HTTP-запросов. PDF и изображения не включаются в Git.
Это отдельный источник `guidebook_antalya_2023`, не данные AllClimb.

## Извлечение

Python 3.12, отдельное окружение:

```powershell
python -m pip install -r scripts/guidebook-requirements.txt
python scripts/guidebook_extract.py "D:\path\guidebook Antalya 2023.pdf"
python scripts/guidebook_prepare.py output/catalog/antalya-2023
```

На Windows доступен альтернативный встроенный OCR (требуется английский
пакет распознавания Windows):

```powershell
python scripts/guidebook_extract.py "D:\path\guidebook Antalya 2023.pdf" --engine windows
```

RapidOCR обычно лучше сохраняет таблицы и заголовки; Windows OCR быстрее,
но может пропускать цветной текст и турецкие символы. Его confidence=0 означает
«оценка недоступна». Ни один OCR не подтверждает корректность данных автоматически.
`--pages 4-10` обрабатывает диапазон. Уже записанные страницы пропускаются;
для нового распознавания используйте другую папку `--output`.

Результат: SHA-256 оригинального PDF, `page-NNN.csv` с координатами распознанных
блоков и `candidates.csv` с предполагаемыми строками таблиц. Координаты относятся
к изображению OCR; Windows использует отдельные уменьшенные половины разворота.
CSV — промежуточные файлы проверки, а не новое хранилище приложения.

## Проверка

Для каждой строки сверить на скане район, сектор, название и категорию.
В `area` записать точное имя существующего публичного района из PostgreSQL;
в `sector` — каноническое название сектора, без служебных `LEFT/RIGHT/MIDDLE`.
Подсекторы сохранять отдельно, если они действительно самостоятельные.

`grade_raw` сохраняет исходную категорию. В таблицах часто UIAA, на топосхемах —
французская шкала. Заполнять `grade` проверенной французской категорией (`6B+`);
автоматической конвертации UIAA нет. Неоднозначные категории/мультипитчи оставить
пустыми: в базе будет NULL. Исходная категория остаётся в проверенном CSV.
Ошибки OCR исправляются вручную; `reviewed=yes` ставится только после проверки.
Файл candidates.csv может быть пересоздан; проверенный CSV хранить отдельно.

## Подготовка импорта

Один район на один файл/запуск. Явно указать его существующий ID:

```powershell
python scripts/guidebook_prepare.py output/catalog/antalya-2023 `
  --reviewed output/catalog/antalya-2023/reviewed-geyikbayiri-sample.csv `
  --location-id location_c79a7c4e-e852-4a9b-9fca-27149bb11508
```

Создаётся `import-reviewed.sql`, **не выполняется**. Непроверенные строки
не попадут в SQL. План проверяет точное имя/страну/публичность района,
создаёт сектора и трассы в транзакции, использует advisory lock импорта.
Повтор того же проверенного файла не создаёт дубликаты: ключ — SHA-256 документа
и сохранённый row_key. Не менять row_key после проверки и не объединять разные
издания автоматически. Повторное OCR может изменить набор/порядок кандидатов:
такой файл требует сравнения с уже импортированным.

Маршруты другого источника не объединяются по имени автоматически; это требует
отдельной проверки. Личные тренировки, попытки и их снимки не редактируются.
Внешняя ссылка в БД хранит источник и ключ строки; страница/исходная категория
доступны в проверенном CSV. PDF не размещается на публичном сервере.

Перед выполнением SQL нужны резервная копия и проверка плана. Текущая роль
`climbing_importer_login` предназначена исключительно для AllClimb и не имеет
права записывать `guidebook_antalya_2023`; не расширять её доступ ради выполнения.
План предназначен для оператора миграций. Режим автоматического импорта
непроверенного OCR и еженедельная задача для статичного PDF не предусмотрены.
