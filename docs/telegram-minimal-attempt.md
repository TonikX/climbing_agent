# Обязательные поля пролаза (уточнение требований)

Для Telegram обязательны район, сектор, название трассы, категория и страховка.
Известные значения берутся из выбранной трассы каталога и места тренировки.
Недостающие поля бот уточняет текстом/голосом либо ручной формой.
Пример: «Гейкбаири, Кебап, Engesh 6a, нижняя страховка».

Результат, чистота, стиль, срывы, зависания и комментарий необязательны:
неизвестные значения сохраняются как NULL / unknown и отображаются «Неизвестно».
Логические зависимости результатов сохранены.

В Reply-клавиатуре отсутствует «Главное меню». Тестовый режим доступен администратору.
После старта — краткая подсказка и кнопка подробной инструкции.
Поиск трассы по названию предлагает похожие совпадения вместо просмотра всего каталога.

Нужна миграция 20261026_0022. На сервер переносить через совместимую release-ветку,
в которой 0021 следует за 0019; историческую строгую 0020 на сервере не запускать.
