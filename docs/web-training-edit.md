# Редактирование тренировок на сайте

Открыть «Тренировки», выбрать тренировку и нажать «Изменить тренировку».
Доступны дата, тип места (скалы / скалодром), длительность в минутах,
самочувствие и заметки. Пустые длительность, самочувствие и заметки удаляют
ранее записанные значения. Форма работает и для текущих, и для завершённых
тренировок; статус и попытки не меняются. Район и сектор пролазов эта форма
не редактирует.

После сохранения карточка остаётся открытой, список и статистика обновляются.
При переносе даты за выбранный период тренировка исчезнет из списка этого
периода, но останется доступной в открытой карточке. Деморежим не пишет в API.

## HTTP

`PATCH /api/v1/trainings/{id}` — авторизация пользователя, для браузерной
cookie-сессии обязательны Origin и `X-CSRF-Token`. Поддерживается
`Idempotency-Key` для безопасного повтора запроса.

```json
{
  "expected_version": 3,
  "date": "2026-10-01",
  "environment": "outdoor",
  "duration_minutes": 95,
  "physical_state": "Хорошо",
  "notes": null
}
```

Изменяются только переданные поля. Дата и тип места не принимают null;
длительность допускает null либо 1–10080 минут. Заметки — до 10000 символов,
самочувствие — до 2000. `expected_version` обязателен. При несовпадении версии
возвращается 409: закрыть форму, обновить страницу и повторить правку.
Чужая или отсутствующая тренировка — 404; неизвестные поля — 422.
Изменение блокирует тренировку и увеличивает её версию в той же транзакции.
Миграция БД для этой функции не требуется.
