# Статистика

`get_climbing_statistics` выполняет агрегацию в PostgreSQL и исключает
`is_test=true`.

Поддерживаемые scopes:

- `week` — текущая неделя и краткое сравнение с предыдущей;
- `month` — текущий месяц и сравнение с предыдущим;
- `custom` — `dateFrom`/`dateTo`;
- `route` — только `routeId` или совпадение имени;
- `projects` — актуальные проекты, default limit 10;
- `records` — компактные общие агрегаты без исходных attempts.
- `last_training` — последняя завершённая тренировка;
- `progress` — помесячная динамика за последние шесть активных месяцев;
- `grades` — агрегаты по категориям;
- `locations` — агрегаты по локациям.

Ответ содержит число тренировок, трасс и попыток, закрытые трассы, активные
проекты, flash/redpoint и максимальную категорию. Детали конкретной трассы
запрашиваются отдельным targeted query.

## Telegram без LLM

Кнопка `📊 Статистика` открывает детерминированное меню. Команды-к callback
обработчики напрямую вызывают FastAPI и форматируют DTO в TypeScript. DeepSeek
не вызывается для текущей и последней тренировок, недели, месяца, прогресса,
категорий, локаций, проектов, рекордов и полного списка текущих попыток.
