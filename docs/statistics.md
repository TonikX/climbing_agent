# Статистика

`get_climbing_statistics` выполняет агрегацию в PostgreSQL и исключает
`is_test=true`.

Telegram-инструменты используют ID отправителя из доверенного runtime-контекста,
заменяя переданные моделью имя и ID пользователя. Кнопки и свободные запросы
читают одну историю. Последняя тренировка — последняя завершённая по дате,
с хотя бы одним нетестовым пролазом; пустые и полностью тестовые исключаются.

Стиль считается по первому успешному прохождению каждой route session:
Onsight, Flash, Red Point или «стиль не указан». Неуспешные попытки и повторные
успешные попытки той же route session не увеличивают счётчики стилей.
`unknown` не преобразуется автоматически в Flash или Onsight.
Кнопка «Пройденные трассы» в активной тренировке показывает группы трасс,
у которых есть нетестовая попытка `result=send`, со всеми их попытками.

Старые данные могут содержать `send` при упоминании срывов в notes и отдельные
legacy route sessions для повторов одной трассы. Статистика использует
структурированные поля; для таких записей требуется отдельное исправление данных.

Поддерживаемые scopes:

- `week` — текущая неделя и краткое сравнение с предыдущей;
- `month` — текущий месяц и сравнение с предыдущим;
- `custom` — `dateFrom`/`dateTo`;
- `route` — только `routeId` или совпадение имени;
- `grade` — точная категория `grade` с необязательными `dateFrom`/`dateTo`;
- `projects` — актуальные проекты, default limit 10;
- `records` — компактные общие агрегаты без исходных attempts.
- `last_training` — последняя завершённая тренировка;
- `progress` — помесячная динамика за последние шесть активных месяцев;
- `grades` — агрегаты по категориям;
- `locations` — агрегаты по локациям.

Ответ содержит число тренировок, трасс и попыток, закрытые трассы, активные
проекты, flash/redpoint и максимальную категорию. Детали конкретной трассы
запрашиваются отдельным targeted query.

## Telegram без LLM

Кнопка `📊 Статистика` открывает детерминированное меню. Команды-к callback
обработчики напрямую вызывают FastAPI и форматируют DTO в TypeScript. DeepSeek
не вызывается для текущей и последней тренировок, недели, месяца, прогресса,
категорий, локаций, проектов, рекордов и полных списков попыток текущей или
последней тренировки.

Свободный запрос использует LLM только для выбора `scope` и фильтров. После
вызова `get_climbing_statistics` плагин применяет тот же детерминированный
formatter, отправляет текст в текущий Telegram-диалог и завершает tool batch
через `terminate=true`. Поэтому дополнительного LLM-вызова для оформления
ответа нет. Если активный канал не предоставляет direct-delivery capability,
инструмент возвращает уже отформатированный текст обычному runtime.
