# Импорт каталога AllClimb

## Реализовано

Команда `python -m app.allclimb` разбирает HTML через BeautifulSoup, сохраняет
общий каталог в PostgreSQL и подходит для запуска отдельной джобой.
Поддерживаются Россия (`RU`) и Турция (`TR`). LLM не используется.

Режимы:

- `--html COUNTRY SOURCE_URL FILE` — сохранённая публичная HTML-страница.
- `--sitemap-file FILE --area-country 'Название=TR'` — только названия районов
  из sitemap; страна задаётся проверенной оператором привязкой.
- `--seed COUNTRY URL` — последовательные обычные GET по опубликованным
  ссылкам. Проверяется robots.txt, включая ограничения для AI-агентов;
  при запрете, 401/403/429, редиректе или неизвестной разметке запуск прекращается.
- По умолчанию — проверка без записи. `--apply` сохраняет результат в БД.

Страна не выводится из языка страницы. Для HTML-сидов оператор указывает
проверенную страну, а парсер берёт только ссылки внутри выбранного региона
или района. В URL AllClimb иерархия: регион → район → сектор → трасса.
Регион сохраняется в `locations.region`, страна в `locations.country`, район
в `locations`, сектор в `sections`, трасса в `routes`.

Для идентичности используются `external_refs(system=allclimb)` с реальной
канонической ссылкой. Если HTML не содержит native ID, `external_id` равен
`url:` + SHA-256 ссылки; это идентификатор по URL, не выдуманный ID AllClimb.
Повторный импорт сохраняет внутренние ID. Неизвестная категория не стирает
известную. Смена родителя/конфликт источников требует ручной проверки.
Не происходит объединения с личным каталогом по совпадению названия,
удаления отсутствующих записей или изменения личных пролазов и их снимков.

## Полнота и ограничения

Текущие HTML-запуски имеют статус `partial`, а не «полный каталог страны».
Кнопка AJAX «Загрузить ещё» фиксируется как `ajax_continuation_not_fetched`.
Обычная HTML-пагинация `rel=next` поддерживается. Число сетевых страниц
ограничено `--max-pages` (по умолчанию 100); интервал — не менее 2 секунд
и не меньше Crawl-delay. Запрещены сторонние адреса, токены в URL,
авторизация, выполнение JavaScript и воспроизведение X-AC-Token.

Ранее AllClimb защищал продолжение списков AJAX-токеном; автоматическая
проверка отклонила попытку воспроизвести этот запрос. Парсер его не выполняет.
Для полноценного обновляемого каталога нужен разрешённый источник/API/выгрузка.
Сохранённые HTML можно разбирать независимо от сетевой доступности.

На сохранённой странице Джан-Тугана проверены 1 район, 26 секторов и 50 трасс.
В сохранённом sitemap есть Geyikbayırı, Турция; этот документ не содержит
его секторов и трасс. Эти цифры не означают полноту России или Турции.

## Запуск в Docker

Настройте защищённую переменную `IMPORTER_DB_PASSWORD` в `.env.public`.
Миграция `20261013_0015` и `app.migrate_public` создают отдельную роль
`climbing_importer_login`, наследующую `climbing_catalog_importer`.
Она может читать/добавлять/обновлять общий каталог и отчёты, но не удалять
каталог, менять личные данные или читать тренировки. API и воркеры не получают
пароль импортера. Сервис `importer` находится в профиле `import` и постоянно
не запускается.

Проверка сохранённой страницы без записи:

```bash
docker compose --env-file .env.public -f compose.public.yaml --profile import \
  run --rm --no-deps -v /path/to/snapshots:/input:ro importer \
  python -m app.allclimb \
  --html RU 'https://allclimb.com/ru/list/Кабардино-Балкария/Джан-Туган/' /input/sample.html \
  --sitemap-file /input/sitemap.xml --area-country 'Geyikbayırı=TR'
```

Для записи добавьте `--apply`. Для сети используйте проверенные `--seed RU URL`
и `--seed TR URL`; если robots.txt запрещает доступ, команда остановится.
Не выбирайте другой User-Agent или адрес для обхода запрета.

`catalog_import_runs` хранит время, источники, страны, числа созданных/
обновлённых/неизменённых записей, предупреждения и результат запуска.
Advisory lock действует до конца сетевого сбора и сохранения. При ошибке
каталог откатывается атомарно, отчёт сохраняется как `failed`. После падения
незавершённый запуск помечается `interrupted` при следующем запуске.
Сетевые ошибки возвращают ненулевой exit code; частичный успешный импорт — 0
с явным `status=partial`. Вывод команды — отчёт, а не копия HTML или токенов.

## Будущая джоба

Планируемое расписание: понедельник, 04:00, Europe/Moscow. Можно запускать
эту же одноразовую команду через systemd timer или планировщик backend.
Перед включением нужно согласовать доступный обновляемый источник и проверить
его охват. Еженедельная задача сейчас не создаётся и не включается.
