# Запись пролаза и текущая тренировка

При записи текстом или голосом обязательны: регион, сектор, название трассы,
категория, чистота, стиль и страховка. Регион и сектор передаются в каталог
PostgreSQL и сохраняются в снимке попытки, включая первую трассу тренировки.
Уже заданные регион и сектор текущей тренировки можно использовать повторно.
Сектор не наследуется при смене региона.

LLM возвращает частично заполненный `Intent(kind=attempt)`; она не подставляет
верхнюю страховку или отрицательную чистоту вместо неизвестных значений.
Если данных не хватает, backend сохраняет личный черновик в `dialog_states`
и спрашивает только недостающие поля. Продолжить можно текстом или голосом.
Черновик связан с конкретной активной тренировкой, действует 30 минут и
не попадает в статистику. `/cancel`, завершение тренировки или начало другой
формы отменяют черновик. Ответ, пришедший после отмены, не создаёт попытку.

Flash, onsight и redpoint позволяют определить чистоту. Срыв или зависание
всегда означает нечистый пролаз, даже если модель вернула `clean_ascent=true`.
Противоречивое сочетание «нечисто + flash/onsight/redpoint» без сведений о
срывах/зависаниях требует уточнить стиль. Нулевые счётчики сами по себе не
доказывают чистоту. Сохранение и подтверждение выполняются одной транзакцией.

Текст — один запрос к DeepSeek; голос — Whisper и один запрос к DeepSeek.
Каждое уточнение расходует обычную квоту AI; форматирование, меню, просмотр
и кнопочное редактирование модели не вызывают. Контекст модели ограничен
личным черновиком, последней трассой и метаданными выбранной тренировки.

В главном меню активная тренировка открывается кнопкой «🧗 Текущая тренировка».
Экран сразу показывает все попытки, включая помеченные тестовыми, место
тренировки и кнопки записи, изменения места и завершения. До 15 попыток
имеют прямые кнопки редактирования; для остальных есть список с пагинацией.
Редактор поддерживает изменение через кнопки/LLM и подтверждённое удаление.
Тестовые попытки по-прежнему исключены из статистики.

`/journal` и `/start` показывают постоянную Telegram-клавиатуру с кнопкой
«🏠 Главное меню». Её текст обрабатывается как служебная команда, даже во
время заполнения формы. Telegram Bot API не даёт добавить произвольную
нативную кнопку рядом с системной «Меню»; используется `ReplyKeyboardMarkup`
над полем ввода. Эта клавиатура остаётся доступной на вложенных экранах.
Для настройки системной «Меню» при развёртывании выполните
`docker compose --env-file .env.public -f compose.public.yaml exec -T worker-ai python -m app.configure_telegram`.
Первый пункт списка команд — `/journal`. Скрипт меняет настройки бота,
не отправляет сообщения и не имеет доступа к журналу.

Пример полной записи:
«Гейкбаири, сектор Кебап, Engesh 6a, с зависанием, нижняя страховка».
Результат: регион Гейкбаири, сектор Кебап, Engesh, 6a, чисто Нет,
стиль С зависанием, страховка Нижняя.
