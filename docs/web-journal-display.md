# Журнал тренировок и выбор периода

Из карточки пролаза убраны строка «Запись №… · попыток…» и повторное поле «Чистота».
Метка результата показывает чистый пролаз, нечистое достижение конца, недостижение конца
либо неизвестный результат/чистоту. Стиль и страховка остаются отдельными.

Периоды: Неделя, Месяц, Год, Всё время. Свой интервал выбирается полями дат.
«Всё время» очищает даты, URL сохраняет пустые from/to для обновления страницы.
GET /api/v1/statistics/all возвращает сводку и категории без ограничения дат,
с фильтрами категории, региона и района. Журнал и прогресс используют тот же диапазон.
Миграция БД не требуется; публикация требует обновить API и веб-образ.

Категории в простом и расширенном обзоре открывают один общий список пролазов
с теми же фильтрами, пагинацией и обработкой ошибок.
Неизвестная длительность в строке журнала скрыта; известное число минут отображается.
Отдельный пункт «Прогресс» убран, графики остаются в расширенном обзоре.
Старая ссылка ?page=progress открывает обзор.
