# Возобновление последней тренировки

В главном меню без активной тренировки доступна кнопка «↩️ Возобновить последнюю
тренировку». Бот показывает дату и просит подтверждение. Кнопка также доступна
в сводке последней завершённой тренировки в меню «Тренировки и пролазы».

Возобновляется только последняя завершённая тренировка пользователя, по дате,
времени создания и ID (тот же порядок, что в истории). Учитываются и тестовые
тренировки. При наличии активной тренировки возобновление запрещено.

ID, дата, исходное время начала, место, попытки и заметки сохраняются. Статус
меняется на `active`, `completed_at` и ранее заданная длительность очищаются.
Длительность снова рассчитывается от исходного начала, включая перерыв;
при завершении через API можно задать её вручную. Версия увеличивается.

HTTP: `POST /api/v1/trainings/{training_id}/resume`, тело
`{"expected_version": 3}`, обычная авторизация пользователя, опциональный
`Idempotency-Key`. Ответ — `TrainingResponse`. Чужой ID возвращает 404,
устаревшая версия, наличие активной или выбор не последней тренировки — 409.
Все изменения сериализованы блокировкой пользователя.

Кнопки не вызывают LLM. После успешного возобновления старый диалог ввода
сбрасывается, меню показывает текущую тренировку. Миграция БД не нужна.
