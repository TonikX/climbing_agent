# Изменение пролаза на сайте

Открыть тренировку и нажать «Изменить пролаз» у нужной попытки. Работает
для текущих и завершённых тренировок, без LLM.

Редактируются название, категория, достижение конца, чистота, стиль, страховка,
срывы, зависания, заметки и тестовая отметка. В разделе «Район и сектор»
доступен поиск по каталогу и ввод своих названий. Изменение места относится
к выбранной попытке; общий каталог не переименовывается. Число попыток
в агрегированной записи эта форма не изменяет.

Onsight / Flash / Red Point выбирают чистоту и достижение конца. Положительные
срывы и зависания исключают чистый пролаз. Для исправления такого пролаза
на чистый нужно исправить счётчики, стиль и противоречащие заметки.
Пустые счётчики и заметки очищают значения. Неизвестные результат и страховку
нужно уточнить перед сохранением. Неизменённые поля в PATCH не передаются.

Используется существующий `PATCH /api/v1/attempts/{id}` с версией тренировки,
CSRF и ключом идемпотентности. Затем GET тренировки получает нормализованные
backend значения. При сетевой ошибке повтор с теми же данными использует тот
же ключ. При 409 нужно обновить страницу перед новой правкой.

Карточка, список и статистика обновляются. Тестовый пролаз исчезает из обычного
просмотра и статистики; вернуть его в реальные можно через тестовый режим бота.
Деморежим не обращается к API записи. Миграция БД не нужна.
