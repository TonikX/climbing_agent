# Старое развёртывание плагина без Compose

Актуальная инструкция полного стека находится в `docs/docker-deployment.md`.
Этот документ сохранён для отката к прежнему systemd-развёртыванию.

Git — источник кода. Данные журнала находятся в PostgreSQL, OpenClaw config —
вне репозитория.
Не использовать исторические файлы `server-baseline` как источник релиза.

Для первого перехода с каталога без Git (`/root/climbing-journal`) создать
соседний checkout выбранного commit, сохранив прежний каталог для отката.
Не выполнять `git init`, `reset --hard` или копирование поверх рабочей версии
без проверки различий и резервной копии.

В новом checkout:

```sh
npm ci
npm test && npm run plugin:build && npm run plugin:validate
```

Только после успеха всех проверок можно переключить путь установки плагина
на новый checkout штатной командой OpenClaw, сохранив permissions восьми
инструментов. Точную команду проверять по
`openclaw plugins --help` установленной версии. Затем:

```sh
openclaw gateway restart && openclaw plugins inspect climbing-journal --runtime --json
```

Ожидается `loaded`, восемь tools и отсутствие diagnostics. Сравнить контрольные
суммы данных до/после при отсутствии пользовательских записей. Записать commit
SHA релиза. Skill устанавливать из `skills/climbing-journal/SKILL.md` после
сравнения с серверной копией.

Откат: вернуть прежний путь плагина и предыдущую сборку, затем перезапустить
gateway. Откат данных выполнять только из отдельной резервной копии PostgreSQL.

Текущая подготовка репозитория сама не переключает production на новую структуру.
